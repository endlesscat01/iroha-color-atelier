# iroha — 色を採集する

スマホ・PCのブラウザで使う、画像からの色抽出アプリ。依存パッケージやサーバー処理は不要です。

## 使い方

- 「撮影する」からスマートフォンのカメラを開く（端末・ブラウザによって画像選択になる場合があります）。
- 「画像を選ぶ」で写真を読み込む。画像は端末内で処理されます。
- 色数を5〜7色から選択。「再抽出」で別の画素から色を採集します。
- コードをタップしてコピー。抽出位置の番号は色の一覧順に対応します。
- 下の色を選び、キャンバスを指・マウスでなぞって混色。「混ぜ直す」で自動配置します。
- 「JPGで保存」で写真・色・混色をまとめた保存用レイアウト、またはHEX/RGB付きの色一覧を書き出します。

初期表示はアプリで描画したデモイメージです。混色は透明色の乗算合成による視覚的な表現で、実物の顔料の厳密な再現ではありません。単色画像は複数の異なる色を含まないため、同じコードが並ぶことがあります。

## ローカル起動

このフォルダで `node preview.cjs` を実行し、表示されたURLを開きます。`dist/index.html` を直接開いても基本動作しますが、コピーや共有はHTTPS/localhostを推奨します。

スマートフォンでは公開済みHTTPS URLを開いてください。ネイティブのiOS/Androidストアアプリではありません。
